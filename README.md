# 📈 Sales Prediction Using Machine Learning

## 📌 Project Overview

Sales prediction is a crucial task for businesses to estimate future product demand and optimize marketing strategies. By analyzing factors such as advertising expenditure, target audience, and marketing channels, companies can make informed decisions to maximize revenue and minimize costs.

This project uses Machine Learning techniques to predict product sales based on advertising and marketing data. The model learns patterns from historical data and forecasts future sales with high accuracy.

---

## 🎯 Objectives

* Analyze the relationship between advertising and sales.
* Perform data preprocessing and exploratory data analysis (EDA).
* Train machine learning models to predict future sales.
* Evaluate model performance using regression metrics.
* Generate accurate sales forecasts for business decision-making.

---
